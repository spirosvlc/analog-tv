# Analog TV product overview

Analog TV combines continuous virtual broadcast channels, IPTV M3U and HLS,
YouTube subscriptions, a green guide, Android/CRT playback, and a 24-hour
weather television channel with hourly forecast refresh.

For Home Assistant setup, see the repository [README](../README.md).
For the renamed add-on and SQLite migration, see [MIGRATION.md](MIGRATION.md).
For local Admin sign-in, see [README.md](../README.md).
